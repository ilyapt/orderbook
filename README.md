I wrote this order book matching engine in Go primarily as an exercise. It is single-threaded, uses no pointers, and performs no memory allocations in its critical paths. Orders and price levels are stored in flat arrays and linked via indices rather than references (indexed list instead linked list), which ensures that the garbage collector does not interact with the order book. Adding, canceling, or executing an order takes only a few nanoseconds.

An order id is a specific code containing both a slot index and a sequence number. This allows for extremely fast, constant-time order cancellation without the need for hash tables. Furthermore, old or previously canceled orders are effectively locked out.

The project consists of three modules. The first, `levels`, maintains queues of orders for each price level, tracking both price and volume. The second, `book`, organizes these levels by price for both buyers and sellers. The third, `matching`, handles the execution of limit orders, supporting GTC, IOC, FOK, and PostOnly order types. All modules have been thoroughly tested, including the use of randomized data to verify correctness against a reference model. The repository includes a benchmark comparing these queues to standard implementations based on `container/list`; the results show that adding and canceling orders is approximately 10 times faster. With one million active orders, performance is 8 times higher—all achieved without a single memory allocation.

Additionally, the price index implementation was benchmarked against red-black trees (from `emirpasic/gods`) and B-trees (from `google/btree`). The simple sorted array I used proved faster for searches: 2–8 times faster for narrow price ranges, 20–40% faster across the entire order book, and 10 times faster for depth-based traversal. Tree structures only performed better when frequent modifications to levels deep within the order book were required—a relatively uncommon operation. These benchmarks are not included in the repository to avoid adding unnecessary dependencies for testing.
